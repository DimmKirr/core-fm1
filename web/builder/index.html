InstallerEditor

Firmware builder for the M-VAVE FM-1

Pick what goes into your firmware: the same items, rules and size estimate as make builder. What does not fit is shown, with by how much; you decide what to leave out.

Loading the builder
The builder's rules are its Python code, run in this page (Pyodide, about 13 MB the first time, then cached by the browser).

Load a .config file (or paste one)

The size estimate appears once Python has started.

Select an item to see what it does and what it costs.

Your configuration

Cloud builds are not live yet. Build it yourself from a checkout: python3 tools/optimist.py build --config FILE (or open it in the menu: python3 tools/optimist.py builder --config FILE).
