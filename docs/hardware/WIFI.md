# Superseded: see docs/hardware/wifi/SPECSHEET.md

This file was a 2026-10-26 copy of the WiFi hardware fact sheet. It was retired on 2026-11-04
because it carried superseded facts (an SDIO bus, a WPDMA block at `0x40000`, a bus gate) and
vendor identifiers that the current sheet no longer uses. A second barrier document is a
contamination risk for the implementer, so its content is not kept here; the repository history
retains it.

The current fact sheet is `docs/hardware/wifi/SPECSHEET.md`; the methodology and the permitted
references are in `docs/hardware/wifi/CLEAN_ROOM_METHODOLOGY.md`. References elsewhere to "WIFI.md §7.5"
(the RT2800 ancestry statement) correspond to SPECSHEET §0 ("IP ancestry") and §7.
