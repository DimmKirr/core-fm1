# Everything here is read off the bar under each value, which is the parameter's amount drawn as a
# width in pixels. That makes a screenshot into a number, so the claims can be arithmetic rather
# than "the screen changed": the ratio walks its list one entry at a time, stops at both ends,
# means a frequency in FIXED, and -- the claim that matters -- is nothing but the COARSE and FINE
# bytes, which SHOW ALL puts back on the page so they can be read directly.
#
# OPERATOR bank 1 is LEVEL, RATIO, DETUNE, MODE, so RATIO is KNOB2 = enc 3 and MODE is KNOB4 = enc 5.
0 btn 8
200 btn 6

# click up snaps to the entry above; from there every click is one entry.

1400 enc 3 1
1600 shot

# and back down over the same ground, which has to retrace exactly
