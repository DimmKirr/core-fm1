# FM Lab -- the panel: pages that walk their own banks, and the black keys that pick an operator.
#
#   build/host/fmlab build/host/panel tests/panel.txt
#
# Nothing here is about sound, so there is no chord to listen to. What is checked is the MIDI the
# instrument sends -- a key that picks an operator must send nothing at all -- and the screens,
# which have to differ when the bank moves on and come back around when it wraps.
0 btn 8

# OPERATOR shows fourteen parameters four at a time, so four banks. Press and HOLD EDIT five times:
# a held EDIT is the page, and pressing it again there walks the banks and wraps. (A tap of EDIT is
# a different thing entirely and is tested in focus.txt.)
200 btn 6 600
1100 shot
1300 btn 6 600
2200 shot
2400 btn 6 600
3300 shot
3500 btn 6 600
4400 shot
4600 btn 6 600
5500 shot

# ENVELOPE is a page of its own: arriving starts at its first bank, pressing again walks it.
5700 btn 4 600
6600 shot
6800 btn 4 600
7700 shot

# Back to OPERATOR -- a different page, so its first bank again, not the bank ENV was left on.
7900 btn 6 600
8800 shot

# F#4 is the sixth black key: OP6. It must change the screen and send no note.
9000 keys 0x2000
9200 keys 0
9400 shot

# F#3 is the first: OP1. A different operator, so a different screen again.
9600 keys 0x2
9800 keys 0
10000 shot

# A white key on the same page is still a key.
10200 keys 0x1
10400 keys 0

# And on HOME the black key is an ordinary key once more.
10600 btn 8
10800 keys 0x2000
11000 keys 0

# Held across a page change: the note was started as a note, so it has to end as one. If the page
# took the key away on the way up, this note would hang.
11200 keys 0x1
11400 btn 6 600
12300 keys 0

# MONO and POLY are the top two black keys, and they only mean that on OPERATOR, where we still
# are. Like the operator keys they must not sound. The proof that the switch did anything is the
# chord: in mono it is one note, so it has to be markedly quieter than the same chord in poly.
12700 keys 0x100000
12900 keys 0
13100 keys 0x4880
13700 keys 0
13900 keys 0x400000
14100 keys 0
14300 keys 0x4880
14900 keys 0

# Legato, which is the whole point of mono. Back to mono, and over to a plucked voice so that the
# first note has visibly died away by the time the second arrives. Press the second while the first
# is still down and it is a slur: no attack of its own, so it comes in at whatever is left. Strike
# the same note cleanly afterwards and it is loud again.
# (Keys 7 and 9 are white; the black ones on this page belong to the operators.)
15100 keys 0x100000
15300 keys 0
15400 enc 6 12
15600 keys 0x80
16700 keys 0x280
17000 keys 0
17400 keys 0x200
17700 keys 0

# Fall-back: let go of the top note while an older one is still down and you drop back to that one
# rather than to silence. A sustaining voice, so there is something left to hear.
18000 enc 6 -7
18200 keys 0x80
18500 keys 0x280
18800 keys 0x80
19500 keys 0
20300 end
